문제의 출발점, 제품 가설, 구현 구조, 실제 시연, 보완점과 배운 점을 담은 9장 발표입니다. 발표 내용의 기준은 2026-10-08이며, 구현·미래 확장·검토 중인 제안을 구분합니다.

- **[PDF 보기·다운로드](Jarvis-Pet-Presentation.pdf):** 확정된 웹슬라이드를 16:9 비율의 9쪽 PDF로 변환했습니다. 영상은 정지 화면이며 각 장 하단에서 근거 문서를 열 수 있습니다.
- **[웹슬라이드 파일](index.html):** 실제 GIF 시연과 발표 메모를 포함합니다. GitHub에서는 코드가 보이므로 아래 방법으로 내려받아 실행하세요.

## 열기

저장소를 내려받은 뒤 이 폴더의 `index.html`을 Chrome 같은 브라우저로 엽니다. 외부 라이브러리나 글꼴을 불러오지 않으므로 인터넷 없이 슬라이드와 시연을 볼 수 있습니다. 근거자료는 GitHub의 서식이 적용된 문서 페이지와 공식 정책 문서로 연결하며, 열 때 인터넷이 필요합니다. 프로젝트 문서는 발표 작성 시점의 Git 기록에 고정해 이후 문서가 바뀌어도 근거가 달라지지 않게 했습니다.

`index.html`만 따로 옮기면 그림과 조작이 빠집니다. 공유하거나 다른 컴퓨터로 가져갈 때는 `presentation` 폴더와 상위 `docs/assets` 폴더를 같은 상대 위치로 유지하세요. 저장소 전체를 가져가는 것이 간단합니다.

GitHub에 HTML 파일을 올리는 것만으로 발표용 웹 주소가 생기지는 않습니다. 이 폴더는 별도 웹 호스팅 설정 없이도 파일로 열 수 있게 작성했습니다.

## 발표 조작

| 조작 | 기능 |
| --- | --- |
| ← / → 또는 아래 화살표 버튼 | 이전 / 다음 장 |
| Home / End | 처음 / 마지막 장 |
| N 또는 발표 메모 | 대본·권장 시간·출처 보기 |
| F 또는 전체 화면 | 전체 화면 전환 |
| T 또는 시작·정지 버튼 | 발표 시간 측정 |
| ↺ | 타이머 초기화 |
| 시연 멈춤 / 시연 재생 | GIF와 정지 화면 전환 |
| 시연 다시 보기 | 현재 시연 처음부터 재생 |

발표 메모는 **현재 화면 위에 표시**되므로 화면을 공유하는 중에는 닫아 두세요. 별도 발표자 화면은 아닙니다. 시간은 직접 시작해야 하며 자동으로 다음 장으로 넘어가지 않습니다. 기기의 동작 줄이기 설정이 켜져 있으면 GIF는 정지 화면으로 시작합니다.

## 수정 위치

- `content.js`: 각 장의 제목, 본문, 발표 메모, 시간, 근거 링크.
- `styles.css`: 색, 글꼴 크기, 구조 그림과 화면 배치.
- `print.css`: 각 슬라이드를 PDF 한 페이지로 출력하는 설정.
- `app.js`: 장 넘기기, 시연 재생, 메모, 타이머.
- `index.html`: 웹 문서와 조작 버튼.

## 사용 환경과 제한

웹 발표와 PDF 출력의 기준 환경은 macOS의 Chrome입니다. 웹슬라이드는 큰 화면에서 16:9 비율로 표시하며 작은 화면에서는 세로로 읽을 수 있습니다. PDF에는 영상 재생·타이머·발표 메모가 포함되지 않습니다. 발표 메모는 웹슬라이드에서 확인하세요.

실제 발표장의 프로젝터, 다른 운영체제·브라우저, 발표자의 발화 시간은 별도 확인 대상입니다.
