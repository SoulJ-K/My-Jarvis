# Jarvis Pet

한 번 태어난 펫과 관계를 이어가며, 함께 성장하는 데스크톱 비서 펫.

Jarvis Pet은 화면 위에서 움직이는 펫을 돌보고 교감하는 경험에서 시작합니다. 펫은 앱을 껐다 켜도 같은 개체로 남으며, 타이머·알람·리마인더 같은 작은 생활 요청을 돕습니다. **펫과의 관계와 생활 속 비서 경험이 중심**입니다.

장기적으로는 사용자를 이해하고 일을 돕는 개인 AI 동반자를 지향합니다. 현재 기본 펫 행동과 비서 기능은 외부 AI 없이 동작하며, **일반적인 자유 대화 AI와 여러 AI의 자동 선택 기능은 제공하지 않습니다.**

> **현재 상태:** 개인용 **v1 후보판**을 준비하고 있습니다. v1은 확정판에 사용할 이름이며, 구현 범위는 기존 PRD의 v0.1(알 → 부화 → 아기 생활)을 유지합니다. 패키지 버전은 `0.1.0`이며, 자연 경과·며칠간의 실사용 검증과 최종 확정은 아직 남아 있습니다.

## 어떤 경험을 만들고 있나요?

처음에는 별빛 무늬의 알과 상호작용합니다. 부화할 준비가 되면 사용자가 장면을 시작하고, 같은 창에서 알이 아기로 태어나는 과정을 봅니다. 이름을 지은 뒤에도 같은 펫과 생활하며 먹이, 수면, 감정, 관계와 짧은 놀이를 경험합니다.

v0.1의 목표는 **알 → 부화 → 아기와 며칠 생활하기**, 그리고 정해진 입력에 대한 짧은 반응·타이머·알람·리마인더를 함께 사용하는 것입니다. 이후 성장 단계와 복잡한 AI 작업은 아직 목표 범위 밖입니다.

## 현재 구현된 기능

| 구분 | 현재 상태 |
| --- | --- |
| 펫 생활 | 알의 기본 반응과 돌봄 기록, 부화 장면·이름 저장, 아기의 먹기·수면·감정·관계·놀이가 앱에 연결돼 있습니다. |
| 기본 비서 기능 | 입력창, 5분 타이머, 날짜·시각을 지정하는 일회성 알람·리마인더와 재시작 뒤 미확인 항목 복원 기능이 있습니다. |
| 저장 | 펫의 단계·이름·기본 상태와 관련 기록을 로컬에 저장하고 복원합니다. |

아기와의 짧은 상호작용은 “안녕”, “잘했어”, “구슬 놀이”처럼 정해진 입력에 반응하는 방식입니다. 타이머는 **5분짜리 하나만** 진행할 수 있습니다. “2분 타이머”, “1분 뒤 알람” 같은 입력은 아직 지원하지 않습니다.

## 실제 Mac에서 확인한 범위

**2026-10-01·06의 격리 Mac 시험 앱에서 기록된 결과입니다.** 10월 6일 전용 시험 앱은 `f822f31` 기준입니다. 기존 알림·복원·잠금 기록에 더해, 아래 오프라인 검사는 이번 후보판 작업 중 사용자 관찰과 저장 상태로 확인했습니다.

- 실행 중 타이머·일회성 알람·리마인더 각각의 macOS 배너·소리 확인
- 예정 시각 전 재실행 후 예약 복원과 후속 배너 확인. 동시 알람·리마인더 각각의 소리는 미확인
- 종료 중 만료된 세 종류의 미확인 복원, 각각 확인 처리 후 재실행 유지
- 잠금 중 타이머 배너·소리와 리마인더 배너 관찰. 해제 후 알람·리마인더 시스템 알림 및 미확인 목록 유지
- 기존 실사용 세션의 후속 보고: 물리 절전 중 만료된 세 종류 모두 복귀 후 미확인 항목으로 유지. 상세 Development Log 반영은 해당 세션에서 진행

**오프라인 확인:** 보존 알의 클릭 반응과 전용 시험 앱의 타이머·알람·리마인더 각각의 앱 안내·시스템 배너·소리를 확인했습니다. 다만 **지금 키우는 알의 개발용 실행에서는 타이머 시스템 알림이 실패**했고, 이 문제는 해결되지 않았습니다. [오프라인 실사용 기록](docs/Jarvis_Pet_Development_Log.md#offline-field-2026-10-06)에서 두 실행 환경을 구분합니다.

메뉴 아이콘 미표시와 소리 미청취 등 최초 문제와 후속 확인은 [개발 기록](docs/Jarvis_Pet_Development_Log.md#notification-field-2026-10-06)에 구분해 보존합니다. 시스템의 표시 신호 `shown`은 사용자가 배너를 보거나 소리를 들었다는 증거가 아닙니다. 정확한 초 단위 전달 지연도 측정하지 않았습니다.

**아직 확인할 것:** 잠금 중 알람의 직접 표시와 알람·리마인더 각각의 소리, 자연 경과 부화·며칠간 아기 생활, 오프라인 상태의 아기 돌봄·대화·재시작을 포함한 전체 흐름입니다. 다양한 화면 환경·Windows·정식 배포용 앱도 미검증입니다. 앱이 완전히 종료되거나 Mac이 잠들어 있는 동안 정시 알림은 보장하지 않습니다.

[완료 판단표](docs/Jarvis_Pet_Technical_Design.md#v1-readiness)와 [실기기 검증 계획](docs/Jarvis_Pet_Technical_Design.md#mac-validation-plan)에서 확보된 근거와 남은 확인을 구분합니다. 며칠 사용이 요구사항이며, 3일은 제안한 관찰 기간입니다.

## 개발 환경에서 실행하기

현재 macOS Apple Silicon 환경을 중심으로 검증하고 있습니다. 배포용 설치 안내가 아니라 개발용 실행 방법입니다.

```bash
npm ci
npm start
```

`npm start`는 앱의 기본 저장 위치를 사용하는 개발 실행입니다. 매번 새 임시 펫으로 시작하는 체험 명령은 아닙니다. 실제 펫과 분리한 체험 경로는 [체험·촬영 준비안](docs/Jarvis_Pet_Technical_Design.md#preview-plan)을 참고해 주세요.

검사 명령:

```bash
npm run typecheck
npm run test:ci
```

`test:ci`는 Node.js 24에서 빌드와 화면 없는 규칙·저장 검사 7개 파일만 실행합니다. PR 자동 검사 설정도 이 명령을 사용합니다. GitHub에서의 실행 확인은 별도이며, [최소 CI 범위](docs/Jarvis_Pet_Technical_Design.md#minimal-ci)를 참고해 주세요.

전체 Electron 검사 명령은 기존 `npm test`입니다. 실제 창과 입력 초점에 영향을 줄 수 있으므로 실행 중인 실사용 검사와 시간을 조율하고 분리된 작업·검사 자료로 실행합니다.

테스트 통과는 실제 운영체제 알림 표시나 장기간 사용 경험의 검증을 대신하지 않습니다. Windows 동작과 정식 배포 패키지도 아직 확인하지 않았습니다.

## 설계 원칙

- **관계의 지속성:** 성장해도 태어난 펫을 교체하지 않습니다.
- **작은 첫 버전:** 큰 AI 동반자 비전과 지금 구현할 v0.1 범위를 구분합니다.
- **로컬 우선:** 펫의 기본 행동과 기억을 특정 AI 제공자에 종속시키지 않습니다.
- **사용자 소유:** 핵심 상태와 기억은 사용자 기기에 우선 저장합니다.
- **과장 없는 상태 표시:** 계획, 자동 검사, 실제 사용 확인을 구분합니다.
