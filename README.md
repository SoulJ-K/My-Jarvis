# Jarvis Pet

**함께 자라고, 해야 할 일을 챙겨주는 데스크톱 비서 펫.**

Jarvis Pet은 화면 위에서 함께 생활하는 작은 펫입니다. 알을 돌보고, 부화를 지켜보고, 이름을 붙이며 관계를 이어갑니다. 앱을 껐다 켜도 같은 펫과 경험이 남습니다.

펫은 타이머·알람·리마인더로 시간을 알려주고, 아기가 되면 **알림 이후 실제로 일을 마쳤는지**도 챙깁니다.

> 현재는 개인용 macOS 앱으로 개발 중입니다. 알 → 부화 → 아기 생활을 바탕으로 **v0.2 사용 경험 개선과 실사용 검증**을 진행하고 있습니다. 정식 배포판은 아직 제공하지 않습니다.

## 함께 생활하는 펫

처음에는 알과 상호작용하며 부화를 기다립니다. 준비가 되면 사용자가 보는 앞에서 부화하고, 태어난 아기에게 이름을 붙입니다.

아기는 먹고, 자고, 구슬로 놀며 생활합니다. 짧은 말을 알아듣고 **몸짓과 감정구슬의 색·밝기**로 반응합니다. 쉬고 싶을 때는 상호작용을 거절하기도 합니다.

기본 생활과 반응은 외부 AI나 인터넷 연결 없이 동작하도록 구성합니다. 자유롭게 긴 대화를 나누는 기능은 아직 제공하지 않습니다.

## 시간을 알려주고, 결과를 챙깁니다

- **타이머:** 제목과 시간·분·초를 정하고 여러 개를 동시에 사용할 수 있습니다. 일시정지·재개·처음부터·취소를 지원합니다.
- **메뉴바 표시:** 기본적으로 3분 남았을 때부터 제목과 남은 시간을 보여줍니다. 처음부터 하나를 고정하거나 표시하지 않도록 선택할 수도 있습니다.
- **알람·리마인더:** 날짜와 시각을 정해 일회성 알림을 예약합니다.
- **아기의 후속 확인:** 알림 후 사용자가 확인하지 않으면 작은 말풍선으로 챙깁니다. **했어요 / 아직이에요 / 취소할게요**로 답할 수 있습니다.
- **재알림과 재촉:** 아직 하지 못했다면 다시 알릴 시간을 정합니다. 아기는 몸의 색과 움직임으로 남은 일을 표현하고, 완료하거나 취소하면 해당 일정의 재촉을 멈춥니다.

**알림을 확인한 것과 일을 완료한 것은 구분합니다.** 메뉴바 표시 여부와 관계없이 알림 전달은 유지됩니다. 타이머 입력에는 `라면 3분 타이머`처럼 ‘타이머’를 적어 주세요.

## 휴지통 간식

아기에게 `간식먹어`라고 말하거나 아기를 Dock의 휴지통으로 끌어 놓아 간식을 요청합니다.

사용자가 휴지통의 일반 파일을 최대 2개 고르고, 마지막 확인을 거쳐 간식으로 줍니다. **선택한 파일은 실제로 영구삭제되며 되돌릴 수 없습니다.** 폴더는 대상에서 제외합니다.

macOS에서 휴지통 목록을 읽으려면 ‘전체 디스크 접근 권한’이 필요합니다. 이는 휴지통보다 넓은 접근 권한이므로 사용자가 허용 여부를 결정합니다. 일반 먹이와 간식은 식사를 마친 뒤 공통으로 15분 간격을 둡니다.

현재 Mac에서 시험 파일 두 개로 목록 열기, 최종 확인 취소 시 보존, 사용자 확인 후 삭제·먹기와 식사 직후 재요청 차단을 확인했습니다. Dock 드롭 감지는 별도 시험에서 확인했으며, 권한 적용 후 Dock부터 실제 삭제까지의 전체 흐름을 다시 검사한 것은 아닙니다.

## 어떻게 성장하나요?

성장은 모습의 변화뿐 아니라 **사용자를 돕는 능력이 깊어지는 과정**을 지향합니다.

알은 시간을 알려주고, 아기는 결과를 챙깁니다. 이후에는 남은 일을 다시 챙기고, 사용자의 패턴을 이해하며, 허용받은 범위에서 일을 돕는 동반자로 성장하는 것이 장기 방향입니다.

현재 구현 범위는 **알과 아기**입니다. 이후 성장 단계와 외부 작업 완료 연동은 앞으로의 개발 과제입니다. 펫이 성장한다고 파일이나 시스템을 다룰 권한이 자동으로 늘어나지는 않습니다.

## 현재 확인 범위와 한계

타이머·알람·리마인더, 아기의 상호작용과 후속 확인 기능은 자동 검사와 현재 Mac에서의 실사용 확인을 진행했습니다. 휴지통 간식도 위에 적은 시험 파일과 입력 경로에서 확인했습니다.

- 자연 경과 부화와 며칠간의 아기 생활은 계속 관찰 중입니다.
- 앱 종료나 Mac 절전 중에는 정시 알림을 보장하지 않습니다.
- 시스템 알림은 macOS의 알림 허용과 실행 환경에 영향을 받습니다.
- 오프라인 상태의 아기 생활 전체 흐름, 이번 버전의 잠금·절전과 다양한 모니터 환경, Windows·정식 배포용 패키지는 확인이 남아 있습니다.

상세한 통과·실패·미검증 기록은 [기술 설계와 검증 기록](docs/Jarvis_Pet_Technical_Design.md#v02-final-review)에서 관리합니다.

## 개발 환경에서 실행하기

현재 macOS Apple Silicon과 Node.js 24를 기준으로 개발합니다. Dock 연결 기능을 빌드하려면 Xcode Command Line Tools와 해당 Node 버전의 헤더가 필요합니다.

```bash
npm ci
npm start
```

`npm start`는 개발용 실행이며, 매번 새로운 시험 펫을 만드는 명령이 아닙니다. 기존 펫을 이어서 실행하거나 시스템 알림을 확인하려면 [Mac 앱 실행 안내](docs/Jarvis_Pet_Technical_Design.md#existing-pet-mac)를 먼저 확인해 주세요.

기본 검사:

```bash
npm run typecheck
npm run test:ci
```

자동 검사는 실제 macOS 배너·소리·잠금·절전과 장기간 사용 확인을 대신하지 않습니다.
